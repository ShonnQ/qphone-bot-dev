# 产品单账本

| 单号 | GitHub | 标题 | 状态 | PR |
|---|---|---|---|---|

> 单号规则：`FR-YYYYMMDD-N`（功能 / 需求）· `PR-YYYYMMDD-N`（缺陷，Problem Report，**唔系** GitHub Pull Request）。
> 单号一律由 `./scripts/new-ticket.sh` 分配，禁手填。GitHub 原生 `#N` 只系链接（Issue / PR 共用计数器）。
> 一次迭代 = 一张单 + 一个 PR；PR 合入后把状态改 `closed YYYY-MM-DD` 并填 PR 号。
