2 · 规则（v1.1 定稿）

① 一条语法：实线＝本机，虚线＝跨机

框内（同一进程/同一台机）一律 1px 实线；跨进程或跨机（ADB、HTTPS）一律 1px 虚线。虚线只做呢两件事。

② 锚点插住，唔穿框

每个节点左右各一个 5px 环状锚点，线只接到环上；线与框留 6px。睇得清「入／出」。

③ 箭头讲流向

每段线右端 4×6px 小三角；双向段（ADB ⇄、HTTPS ⇄）两端都有。

④ 标签入 pill

所有线标签统一：`.tag` pill（7.5px、字距 .8、圆角 9px、底色 `#0b1017`），骑在线中，唔再浮字。

⑤ 活跃＝琥珀，同节点同色

活跃链路 2px `#FBBF24` + 轻外发光；节点也是琥珀 2px。唔再出现蓝紫渐变。

⑥ 非活跃降噪

run 中未走的线 `opacity:.28`；走完回满。

⑦ 跨机段独立成段

ADB 段从 Mac 框拉出来，做成 Mac 框与云机框之间的独立小段（虚线 + 双向箭头 + `ADB ⇄ tcp 10532` pill），唔再塞入 Mac 框。

⑧ 纵向只用一条

模型连 Mobilerun 是唯一纵向段：竖虚线 12px + pill，其余全部横向，避免斜线。
