# QPhone Bot 落地目标清单

> 定位：唔追求「咩都做到」。一条目标 = 一个讲得清嘅起终点 + 一个 adb 机核得到嘅成功判定。
> 每条目标验收时都要**实测跑通**，唔靠模型自述「做完」。

---

## G1 音乐 App → 目标歌单 → 指定歌曲 → 点播

**一句话触发**
「开网易云，播『粤语经典』歌单入面嘅〈海阔天空〉」

**起点**：任意画面（锁屏、桌面、别的 App 都算）
**终点**：目标歌曲**正在播放**（唔系停喺歌单、唔系停喺详情页）

**成功判定（全部要 adb 机核）**
1. `dumpsys media_session` 有 active session，且 `pkg` = 目标音乐 App
2. session `state = PLAYING`（唔系 PAUSED / STOPPED）
3. session metadata 嘅 `title` 命中歌名（歌手可选）
4. 截图留档（人眼复核一次，之后可省）

**要用到嘅能力**
| 能力 | 现况 |
|---|---|
| 打开指定 App | 已有（L0 `am start -W`） |
| 中文落字（搜歌名/歌单名） | 已有（ADBKeyBoard broadcast） |
| 列表内滚动查找（歌单 30+ 首） | **未接**（`scroll` 未实现，现在靠 L2 视觉） |
| 歌单 → 歌曲条目文本比对 | **未做**（L1a snapshot 有 rect，可做行匹配） |
| 播放状态判定 | **未做**（`media_session` 未接入） |

**未决问题（要老板答）**
- 边个音乐 App？（网易云 / QQ音乐 / Spotify / 本机自带）
- 有冇可用账号？歌单系自己嘅还是公开歌单？
- 歌单名同歌名系固定，定每次都唔同？
- redroid 容器有冇音频输出？（**未验**，只影响「听到」，唔影响状态判定）

**风险**
- redroid 无 GMS，部分音乐 App 依赖 Google 服务会闪退（**未验**）
- VIP 歌曲可能只播 30 秒试听 —— 成功判定要接受「试听」定当失败，待定
