v1.2 过程图与实况窗 唔动；只把过程图下面 #log 换成 .chat，事件协议加 kind。

2 · 气泡与卡片（形态全部照 IM）

元素形态说明
你 · me右对齐、扁平填充（主题天蓝 17%）、四角同 16px、无边框、`padding 9px 12px`、≤74%唔用尖角尾巴，靠位置分左右
云机 · bot左对齐、中性填充（白 6.5%）、同圆角同内距连发时首条上方标「云机 · 对话」
分组同边连发 `gap 4px`；换边 `gap 14px`一堆短句唔会散成一列
系统胶囊居中、白 5.5%、999px、8px 等宽「今日 15:29」「1 条任务 · 交畀 Mobilerun」
任务卡同气泡形（16px）+ 语义色内描边：琥珀执行 / 绿完成 / 红要人；头部 + `STEP n / m` + 3px 进度条 + 一行详情形状同气泡一致，只多语义色
反问胶囊`当任务跑` / `就系问下`，999px、天蓝描边只喺 unclear 出现
typing三点 4px、1.2s 跳动，形态同气泡收到首个事件即消失

3 · 规格（照真壳 1.5 zoom × 字体 75%）

项值
会话区`.chat{flex:1 1 0;overflow-y:auto;gap:14px;padding:12px}`
顶部对话头高 ~40px：22px 头像 + 名称 10.12px + 副行 7px 等宽 + 绿点 + 右侧 `⋯`
气泡圆角 16px 四角一致、`padding 9px 12px`、正文 10.12px / 1.65、宽 ≤74%（任务卡 ≤78%）
底色你 `rgba(125,211,252,.17)`；云机 `rgba(255,255,255,.065)`；两者都唔用边框，靠明度差
底部输入栏高 44px：`+` 24px 圆 / 输入框 999px 圆角（占位「给 云机 发消息」）/ 🎙 / 26px 红色圆形发送键
时间唔入气泡；用系统胶囊（跨 5 分钟、跨日、跨任务各一次）
滚动新消息贴底；向上翻锁住 + 「↓ 跳到最新」胶囊
长文本超 3 行折叠 + 「展开」；步骤清单走等宽小字块

5 · 落地清单

步做咩验收
1`serve.py` 事件加 `kind`（`user|chat|task|human|error`）+ `step/of``/turn` 流逐条可辨
2壳 `#log` → `.chat` + 顶部对话头 + 系统胶囊 + 连发分组连发贴组、换边留白
3任务卡随 `phase` 变琥珀 / 绿 / 红真跑「打开设置」全绿
4typing + 「跳到最新」+ 长文本折叠送出即出点，回底一按即到
5底部输入栏改 `+ / 输入 / 🎙 / 发送`（话筒先留位唔接）键位同 IM 一致
6接 `chat / task / unclear` 判定（规则 + 模型兜底）「你好」唔再起 Mobilerun
7四档量测 1600 / 1440 / 1280 / 430 + 长文本 / 连发 / 空态无横向溢出、长句折行正常
