角色系咩同边个讲话边界（做 / 唔做）
人 / 老板用户→ 壳讲一句。唔填端口、唔理 adb
壳薄壳客户端→ /turn；收 SSE只发交代收结果。唔连 adb、唔带 agent、唔装 docker
/turn 服务serve.py :8777→ Mobilerun、qphone.py只翻译与转发。唔自己做决策、唔自己点屏
Mobilerun手机原生 agent（Mac）→ Portal（adb）、→ 模型负责「点」与「看」。唔管容器、唔管端口
qphone.pyadb 配套层→ 云机（adb）容器 / 状态 / 装包 / 截图。唔做决策、唔调模型
Portal APK云机内应用被 Mobilerun 调提供无障碍树与动作执行。唔放业务逻辑
云机Android 13 实例被 adb 操作只知道 adb。唔向壳提供画面或控制入口
模型后端Qbridge :7863/v1被 Mobilerun 调只解题。唔接触设备
三条红线：① 壳 ↔ 云机之间冇直连，画面唔回流（要人时人去云机侧睇屏）；② 唔可以两层 agent 串埋（壳自带 agent 再叫 Mobilerun = token 双花、出错分唔清边层）—— Rakazo 与 dsh 桌面就系因此被否；③ 执行只发生在控制程序一侧，换云机（容器 ↔ 租用实例）只改控制程序，壳一行唔动。
