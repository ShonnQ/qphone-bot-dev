2 · 连线规格（v1.2 新增 · 定稿）

规则做法为何
实线 / 虚线1px；框内同机一律实线，跨进程或跨机一律虚线两种线两个含义，唔再有第三种
颜色静线 rgba(255,255,255,.22)；虚线标签 #bfe9ff；活跃 #FBBF24与运行中节点同色，一套语言
箭头4×5px 三角，右端；双向段（ADB、HTTPS）左右各一唔读字都知流向
锚点节点左右各 4px 环，底 #0b1017、边 1px；线接环，线与框留 5px睇得清「入／出」，线唔穿框
标签7px 等宽、字距 .7、圆角 8、padding 2px 6px，骑在线中字同线唔再抢位
跨机段由 Mac 框右边界 → 云机框左边界，独立一段虚线 + 双向箭头 + `ADB ⇄ tcp 10532`物理事实：Mobilerun 在 Mac，Portal 在云机
纵向段模型挂 Mac 框外正下方：10px 竖虚线 + `HTTPS ⇄ api.x.ai`全图唯一竖线，其余全横
活跃态已走段 2px 琥珀 + 8px 外光；未走段 opacity .28；节点同步 2px 琥珀内边框闪缩 1.1s一眼睇到进度位置
窄窗<1100px：线缩到 38px 后整段换行，云机组居中，标签保留唔留悬空线
